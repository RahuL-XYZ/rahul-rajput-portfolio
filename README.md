# Rahul Rajput — Interactive Desktop OS Portfolio

A cinematic, desktop-inspired portfolio built with React, Vite, Three.js / React Three Fiber, GSAP, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Customize before publishing

1. In `src/App.jsx`, replace `your.email@example.com` with your actual email.
2. Replace generic GitHub and LinkedIn URLs with your profiles.
3. Add your real resume file to `public/` and update the Resume window to download it. The current Resume window creates a text draft and explicitly marks it as a draft.
4. Verify experience dates and responsibilities, project descriptions, and technology lists.
5. Add project screenshots, demo URLs, and repository links where you're allowed to share them.
6. If you add audio, use a properly licensed audio asset and connect it to the sound toggle. The current toggle is a UI preference control and does not play a soundtrack.
7. The app is responsive and respects `prefers-reduced-motion`. The 3D scene uses a capped device pixel ratio and no zoom controls for performance.

## Notes

- Project descriptions are portfolio summaries, not claims of confidential or public launch status.
- This starter intentionally uses placeholder contact information rather than inventing personal links.
